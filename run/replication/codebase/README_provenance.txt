Angrist & Krueger (1991) QJE 106(4):979-1014, DOI 10.2307/2937954
Source: Angrist Data Archive, https://economics.mit.edu/people/faculty/josh-angrist/angrist-data-archive
Downloaded 2026-08-23.
- asciiqob.zip -> asciiqob/asciiqob.txt: 1980 census extract, men born 1930-39, 329,509 obs
  (cols per ak91.sas: LWKLYWGE EDUC YOB QOB POB order per SAS reader). Same data as Angrist-Imbens-Krueger.
- ak91.sas: SAS reader program for asciiqob.txt
- QOB.rar -> QOB/QOB_raw.txt (renamed from "QOB"): ASCII raw data, 1980 census QOB dataset with covariates,
  cohorts 1930-39 & 1940-49 (whitespace-delimited text; .do files read a converted .dta but columns v1..vN map per rename block)
- NEW7080_1.rar -> NEW7080/NEW7080.dta: full 1970+1980 census extracts, all cohorts+covariates (Stata)
- Descriptive Statistics QOB.txt: variable documentation/descriptives
- QOB Table IV/V/VI.do: Stata replication programs for paper Tables IV, V, VI (by Yuqiao Huang, 2008)
  Note: .do files use hardcoded Windows paths -> edit paths; .log files on archive site were 404 (HTML).
No official journal replication package exists (1991 predates mandates); this author-archive deposit is the canonical package.
